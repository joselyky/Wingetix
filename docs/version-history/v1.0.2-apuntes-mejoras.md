# 📋 Apuntes de Mejoras Implementadas — Wingetix v1.0.2

* **Estado:** ✅ **COMPLETADA Y PUBLICADA (`v1.0.2`)**
* **Fecha:** Octubre 2026

---

## 🔄 1. Sistema Oficial de Auto-Actualización (`Auto-Updater`)
- Comprobación silenciosa al arranque (3.5s tras mostrar ventana) y botón manual contra la API oficial de GitHub Releases.
- Modal interactivo con comparativa de versiones, notas de lanzamiento, descarga en vivo (`MB/s`, progreso y tamaño transferido) e instalación desacoplada en 1 clic.

---

## 🛡️ 2. Módulo Dedicado de Puntos de Restauración (`Restore Points`)
- Listado de instantáneas de Windows mediante PowerShell / WMI con elevación bajo demanda.
- Acceso directo en 1 clic al asistente oficial de Windows (`rstrui.exe`) y a las propiedades de Protección del Sistema (`SystemPropertiesProtection.exe`).

---

## 🎮 3. Centro de Gráficos y Control (`Graphics & Control`)
- Telemetría de hardware gráfico para NVIDIA GeForce (`nvidia-smi` + WMI), AMD Radeon e Intel Arc / Iris.
- Lectura de VRAM, temperatura de núcleo, consumo energético (TGP), resolución/hercios y lanzamiento o instalación directa de suites oficiales (*NVIDIA Control Panel*, *NVIDIA App*, *AMD Adrenalin*, *Intel Arc Control*).

---

## 🔒 4. Blindaje *Platform Shield* en el Desinstalador Limpio
- Protección estricta de lanzadores y bibliotecas de videojuegos (*Steam*, *Epic Games*, *Riot Vanguard / Client*, *EA App*, *Ubisoft Connect*, *Battle.net* y *GOG Galaxy*) para purgar residuos de un juego o app sin afectar jamás al cliente ni al resto de juegos instalados.
